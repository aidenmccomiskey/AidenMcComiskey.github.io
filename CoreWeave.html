Overview

CoreWeave is an AI cloud provider that runs large-scale GPU infrastructure for model training and inference. I joined the Applied Training team in May 2026, working on CoreWeave’s internal Kubernetes and SUNK (Slurm-on-Kubernetes) platform, particularly focusing on their new Sandboxes for reinforcement learning. The internship was then extended to allow me to work on LLM quantization.

Qwen3.8-27B quantization: BF16 to NVFP4

Quantized a 27-billion-parameter language model from BF16 to NVFP4, NVIDIA’s 4-bit floating-point format for Blackwell GPUs. The result is 1.79× smaller and delivers higher inference throughput, with no detectable quality regression. The model was queued to be deployed in production.

Humanoid locomotion with PPO

Trained a humanoid robot to run using Proximal Policy Optimization, built as a showcase for CoreWeave’s new Sandboxes product. I scaled the same training setup through four steps:

  1. Fully local, on a laptop.
  2. A local PPO learner with rollouts distributed across cloud Sandboxes.
  3. The PPO learner on a GPU cluster, with rollouts still on Sandboxes.
  4. 64 rollouts, each running its own LLM-generated code inside an isolated Sandbox, feeding experience back to the PPO learner.

The first three steps separated where the policy learns from where experience is collected, which is the pattern that lets RL training scale out.

The fourth showed what Sandboxes are built for: safely executing untrusted, unreviewed code at scale. An LLM wrote the code for each of the 64 rollouts, each Sandbox ran the code it was assigned in isolation, and reinforcement learning ran on the results.
