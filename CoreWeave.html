CoreWeave: ML Engineering Intern

Applied Training team — LLM quantization for production serving and distributed reinforcement learning on GPU infrastructure.

Overview

CoreWeave is an AI cloud provider that runs large-scale GPU infrastructure for model training and inference. I joined the Applied Training team in May 2026, working on CoreWeave's internal Kubernetes and SUNK (Slurm-on-Kubernetes) platform. The internship was originally shorter; the team extended it through September 2026 so I could carry my work toward production.

What I Built

  1. Qwen3.8-27B: BF16 → NVFP4 Quantization
    Quantized a 27-billion-parameter language model from BF16 to NVFP4, NVIDIA's 4-bit floating-point format for Blackwell GPUs. The result is 1.79× smaller and delivers 1.53× higher inference throughput at concurrency 16, with no detectable quality regression across four evaluation suites. I then worked with colleagues on the serving side to scope the evaluations needed to clear it for production. The model was queued to replace the FP8 version in production serving.
  2. Humanoid Locomotion with PPO, Laptop to GPU Cluster
    Trained a humanoid robot to run using Proximal Policy Optimization, built as a showcase for CoreWeave's new Sandboxes product. I scaled the same training setup through three architectures:
    • Fully local, on a laptop.
    • A local PPO learner with rollouts distributed across cloud Sandboxes.
    • The PPO learner on a GPU cluster, with rollouts still on Sandboxes.
    Each step separated where the policy learns from where experience is collected, which is the pattern that lets RL training scale out.
  3. Evals API
    Ran a second workstream triaging and fixing GitHub issues on CoreWeave's evaluation API, the service used to measure model quality.
  4. Platform Tooling
    Contributed bug fixes and documentation corrections to internal cluster tooling while onboarding onto Kubernetes and SUNK.

Stack

Python, Kubernetes, SUNK (Slurm-on-Kubernetes), NVIDIA GPU clusters, NVFP4 / FP8 quantization, LLM inference serving and evaluation, PPO, CoreWeave Sandboxes.
