Overview

EasyCoach is a soccer coaching platform used by professional and amateur clubs (including Villarreal CF) to plan training sessions, manage drills, and develop players. I joined as a Machine Learning Engineer in May 2025 and led the design and rollout of the platform’s AI features, the supporting data infrastructure, and the production deploys that kept them running.

What I built

  • AI drill search

    A hybrid retrieval system that lets coaches search the drill library in natural language (for example, “possession drill for U12s, half-pitch, focus on transition”). A small language-model step interprets the query, then six parallel ranking signals (vector similarity, lexical match, taxonomy match, and others) are merged via Reciprocal Rank Fusion. Serves search across 418 club databases.

  • PostgreSQL vector database

    Designed and stood up the company’s vector database from scratch with pgvector and HNSW indexing. It backs every AI feature on the platform, including the embedding pipeline and the per-tenant isolation that keeps each club’s data separate.

  • AI Autofill

    Coaches describe a drill in one sentence and the platform generates the description, coaching points, equipment list, and age-appropriate adaptations. Built on GPT-4o with a post-generation pass that reconciles equipment across fields. Covered by a 62-test regression suite.

  • AI Diagram

    Turns a drill description into a tactical diagram: a language model extracts entities and movements, a custom layout engine with 10 formation generators positions players and equipment, and a canvas renderer draws the result.

  • Drill categorization

    A machine-learning drill-categorization system using a custom soccer taxonomy, used by 150+ teams. Re-embedded 750+ drills with taxonomy-enriched text, materially improving search relevance.

  • YouTube drill ingestion

    A pipeline that ingests drills from YouTube, enriches and auto-categorizes them, and shares them across tenants with deduplication.

  • Cross-stack data sync

    A dual-write sync layer between the legacy PHP backend and a new Node.js service, keeping MariaDB and the vector database consistent across all tenants.

  • Production ops

    Owned production deploys and incident response for the AI coaching service on AWS ECS.

Stack

Node.js / Express, React, PHP (CodeIgniter), MariaDB, PostgreSQL with pgvector, AWS ECS, OpenAI and Gemini APIs.
